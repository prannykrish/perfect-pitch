## How to run

**On the phone (or anywhere): `https://perfect-pitch-beta-lime.vercel.app`**, the password once per device, then Share → Add to Home Screen. No laptop needed. The installed app keeps its own cookies on an iPhone, so it may ask for the password once more the first time it is opened from the home screen.

```
npm install
npm run samples          # once: downloads FluidR3_GM soundfonts to public/soundfonts (~300 MB, gitignored)
npm run samples:streamed # once: converts the streamed sets (Steinway, e-pianos, mallets, Versilian, Mellotron, bass) to local mp3 (~15 min)
npm run dev              # http://localhost:3000 (the laptop: USB piano, local samples, the same cloud database)
npm run dev:lan          # the same, for the phone: open the "Network" address it prints (same Wi‑Fi)
npm run db:backup        # pull a dated copy of the cloud database into data/backups/
```

`.env.local` (gitignored, never committed) holds `DATABASE_URL` and `DATABASE_AUTH_TOKEN` (Turso), `APP_PASSWORD` (the gate; it also applies to `npm run dev`, which asks once per browser) and `APP_TIMEZONE=America/Chicago` (the zone days are counted in). Without `DATABASE_URL` the app uses the file `data/perfect-pitch.db`, which is now a backup from 2026-11-24 and no longer receives reps; `data/perfect-pitch.pre-cloud-2026-11-24.db` is a second copy of the same moment. The laptop needs the internet to log reps.

**On the iPhone over Wi‑Fi (the way before the cloud; still works):** laptop and phone on the same Wi‑Fi, `npm run dev:lan` (plain `npm run dev` listens on the network too), then type the printed `Network: http://192.168.x.x:3000` address into Safari. If another project is already using port 3000 (on 2026-11-24 his `aladomains` site was), Next picks 3001 and prints that address instead. The first time, Windows may ask whether Node may accept connections: allow it on private networks. Share → Add to Home Screen gives the icon and the full-screen app. Stats are the laptop's database, so reps done on the phone count. The laptop must stay on; "phase: cloud" removes that.

Use a regular Chrome or Edge window (Web MIDI + codecs). The IDE's embedded browser preview cannot decode Opus/AAC and denies MIDI. Plug in the USB piano before opening the page, or press the rescan icon in the MIDI panel. Migrations in `drizzle/` are applied on the first database use, whichever database `DATABASE_URL` names (with it unset, the file `data/perfect-pitch.db` is created if missing).
